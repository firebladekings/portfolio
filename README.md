# OXY // Audio Portfolio

Landing page for Akul Sanjeev Rao, built with React, Vite and Tailwind CSS.

## Develop

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
npm run preview  # serve the build locally
```

Page content (bio, software, tracks, experience, contact email) lives in `src/data.js`.
